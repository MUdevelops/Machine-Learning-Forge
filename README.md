## 🧠 About MLForge

**MLForge** is a hands-on Machine Learning project created to explore and demonstrate the practical implementation of **10 fundamental Machine Learning models**.

The project brings together both **Supervised Learning** and **Unsupervised Learning** techniques in a single Jupyter Notebook, making it useful for learning, experimentation, model comparison, and building a strong foundation in Machine Learning.

Instead of only studying the theory, MLForge focuses on the complete workflow:

```text
Dataset
   ↓
Data Preparation
   ↓
Model Selection
   ↓
Model Training
   ↓
Prediction / Clustering
   ↓
Evaluation
   ↓
Visualization
   ↓
Result Analysis
```

# ⚙️ Getting Started

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/MUdevelops/Machine-Learning-Forge.git
```

## 2️⃣ Navigate to the Project

```bash
cd Machine-Learning-Forge
```

## 3️⃣ Install Dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

## 4️⃣ Launch Jupyter Notebook

```bash
jupyter notebook
```

Then open:

